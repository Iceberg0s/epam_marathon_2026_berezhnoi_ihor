# Звіт по домашньому завданню 
## Що зроблено

Завдання виконано для обох напрямків (Frontend + Backend) на 3 рівні складності. Код повністю перевірений та верифікований локальними автоматичними тестами.

*Примітка щодо деплою:* Хмарне розгортання через AWS Syndicate не виконувалося; вся перевірка бекенду проведена локально через юніт-тести xUnit.
(Але не зовсім зроблено добре, на жаль я не встигав у дедлайн тому верстка й усе інше зроблено на швидкоруч. Тому вибачте за незручності.)

### Frontend
- **Практичне та Рівень 1:** Зверстано картку учасника (`ParticipantCardComponent`) та сторінку `GroupOrderPageComponent` згідно з макетом Figma. Використано Standalone компоненти, Signals та Eager Change Detection.
- **Рівень 2:** Налаштовано взаємодію з API через `GroupOrdersService`. Реалізовано логіку консолідації замовлень, кнопку Submit, модалку підтвердження, обробку помилок та пустих станів. Усе перевірено на моках через демо-посилання (`?demo`).
- **Рівень 3:** Додано фонову синхронізацію кожні 15 секунд (тихі запити через `SKIP_ERROR_TOAST`), кнопку Refresh та обробку втрати з'єднання.

### Backend (.NET)
- **Рівень 1:** Реалізовано ендпоінт `GET /guest/groups/{groupReservationId}/sessions`. Написано бізнес-логіку формування списку учасників і розрахунку загальної суми.
- **Рівень 2:** Створено ендпоінти `GET /reservations/{reservationId}/guest-session-id` (ідентифікація Owner) та `POST /group-reservations/{groupReservationId}/submit` (підтвердження замовлення, агрегація однакових страв по `dishId`, зміна статусів).
- **Рівень 3:** Реалізовано метод `DELETE /guest/groups/{groupReservationId}/sessions/{guestSessionId}` — після видалення сесії повертається оновлений snapshot групи.



## Використання AI

Так, під час виконання завдання активно використовувався AI-асистент. 
- **Для чого:** Допомога з налаштуванням правильної реактивної архітектури в Angular (сигнали, RxJS таймери з `exhaustMap`), генерація boilerplate-коду для .NET сервісів, виправлення помилок типізації TypeScript та супроводу написання тестів (Jasmine/Karma та xUnit).
